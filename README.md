# Guardião

O **Guardião** é um protótipo de aplicação web voltado à segurança pessoal, criado para facilitar o envio de pedidos de ajuda para contatos de confiança em situações de emergência.

**Projeto em desenvolvimento.**

## Funcionalidades

- Alerta de emergência
- Cadastro de contatos de confiança
- Seleção de quem receberá o alerta
- Compartilhamento de localização
- Envio do pedido pelo WhatsApp
- Chat de emergência demonstrativo
- Acompanhamento do alerta
- Armazenamento de dados no navegador
- Interface responsiva

## Tecnologias

HTML • CSS • JavaScript • LocalStorage • Geolocation API • Git/GitHub

## Como funciona

O usuário cadastra seus contatos de confiança e escolhe quem poderá receber seus alertas.

Ao acionar uma emergência, o Guardião obtém a localização do dispositivo e prepara uma mensagem de ajuda para envio aos contatos selecionados.
